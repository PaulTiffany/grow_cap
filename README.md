# grow_cap

Open hardware for a gravity-separated plant cap with independent clean-water and biological-water paths.

This repository is intentionally generic. It does not claim or absorb AlwaysHungrie's Tumbuh/OmegaClaw work. We hope to build alongside that work, and refine interfaces together where collaboration is welcome.

## v0.1 goal

Prove five physical claims before adding biology or automation:

1. clean and biological channels remain separate;
2. gravity produces usable flow;
3. leaks and overflows are visible;
4. the biological basket is removable and serviceable;
5. the cap can be revised from measured printer and hardware tolerances.

See `docs/BAMBU_A1_BUILD.md` for the IdeaSpace Fredericksburg fabrication procedure.
